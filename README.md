# Jeevan Musku — Professional Site

Personal professional website for Jeevan Reddy Musku — about, career journey,
expertise, and a portfolio section reserved for future case studies.

Built with Next.js (App Router), TypeScript, Tailwind CSS v4, and Framer Motion.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Profile, career timeline, skills and certifications live in
[`src/lib/data.ts`](src/lib/data.ts) — edit that file to update site content.
The résumé PDF is served from `public/assets/Jeevan_Musku_CV.pdf`.
